# Research foundations

Researched on 2026-10-12. This framework is an authored adaptation of the following guidance; the sources do not establish that this particular skill improves model performance.

| Source | Adaptation |
|---|---|
| [PRISMA-Search](https://www.prisma-statement.org/prisma-search) and [PRISMA 2020](https://www.prisma-statement.org/prisma-2020) | Transparent source discovery, search reporting, and selection records. A scoped blog is not necessarily a systematic review. |
| [FAIR Guiding Principles](https://www.gofair.foundation/fair-principles) | Identifiers, metadata, provenance, access status, and reuse information. A local manifest is not a claim of full FAIR compliance. |
| [Cochrane Handbook, chapter 14](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-14) | Examine bias, inconsistency, indirectness, imprecision, and missing evidence. Simplified blog appraisal is not a formal GRADE assessment. |
| [How Users Read on the Web](https://www.nngroup.com/articles/how-users-read-on-the-web/) | Clear, scannable, objective writing and meaningful headings. The original study is dated 1997; do not generalize its numerical results to every audience. |
| [Government Analysis Function: charts](https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/) | Choose charts around their message; retain exact data sources, labels, data downloads, and useful explanations. |
| [W3C: Complex Images](https://www.w3.org/WAI/tutorials/images/complex/) | Short identification plus an equivalent longer description for complex visual information. |
| [Creative Commons: reusing content](https://creativecommons.org/reusing-cc-licensed-content/) | Record title, author, source, license, and modifications for reused CC assets; verify specific license conditions. |
| [Zheng et al., Judging LLM-as-a-Judge](https://arxiv.org/abs/2306.05685) | Account for position, verbosity, and self-preference biases when comparing outputs. |

The stage order, registers, default length, scoring weights, and release thresholds are design choices in this plugin, not claims directly prescribed or validated by these sources.
