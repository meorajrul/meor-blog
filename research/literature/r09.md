# R09 — Managing a custom domain for GitHub Pages

Author/publisher: GitHub. Type: official documentation. Accessed: 2026-10-18. Status: **inspected**.

Source: [Managing a custom domain for GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)

Inspected locator: Apex domain; subdomain; custom Actions note.

Application: Set the repository domain and correct apex and www DNS records.

Limit: DNS propagation and certificate issuance are external. With Actions, CNAME alone does not configure the domain.
